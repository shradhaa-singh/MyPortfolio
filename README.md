# Portfolio

This portfolio is built using **React**, **Vite**, and **Tailwind CSS v4**. This project showcases a modern UI/UX approach with smooth transitions and a mobile-first design.

## ✨ Key Features

- **Tailwind CSS v4:** Utilizing the latest CSS engine for faster builds and modern styling capabilities.
- **Modern UI/UX:** Features glassmorphism, neon glow borders, and clean typography.
- **Fully Responsive:** Optimized for all screen sizes, from mobile devices to ultra-wide monitors.
- **Performance Focused:** Built with Vite for near-instant hot module replacement (HMR) and small bundle sizes.
- **Type Safe:** Developed using TypeScript to ensure code quality and easier debugging.

## 🛠️ Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Components:** Shadcn UI & Radix UI
- **Icons:** Lucide React
- **Language:** TypeScript

## 📦 Installation & Setup

1. **Clone the repository:**
   
   git clone [https://github.com/shradhaa-singh/myPortfolio.git](https://github.com/shradhaa-singh/MyPortfolio.git)

2. **Install Dependencies:**

    npm install

3. **Start the development server:**

    npm run dev

**📂 Project Structure**

- src/components/ui - Reusable UI components from Shadcn.
- src/lib - Utility functions and configuration.
- src/assets - Static images and global styles.
- index.css - Custom Tailwind v4 theme configurations.
